# 企业 AI 知识库助手 React 前端

基于 React、TypeScript、Vite、Tailwind CSS 和 React Router 的新前端工程。

当前阶段只包含项目基础设施、公共 AppShell 和页面占位路由，尚未迁移业务页面。

## 安装

```bash
npm install
```

## 开发启动

```bash
npm run dev
```

默认访问：<http://localhost:5173>

开发环境中的 `/api` 请求会代理到 `http://127.0.0.1:8000`。

## 构建

```bash
npm run build
```
